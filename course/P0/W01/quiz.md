# W01 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：AI Infra 全景、从模型计算到 GPU 执行、性能指标、现有能力测评。

1. 画出从 PyTorch 模型算子到 GPU Kernel 的执行链，并指出框架调度、编译/IR 与设备执行各自留下什么证据。
2. 一次在线推理的 TTFT 为 120 ms、随后生成 40 token 且 TPOT 为 15 ms，估算总延迟；为什么 tokens/s 不能替代 TTFT/TPOT？
3. 给定 GPU 利用率 95% 但有效 tokens/s 很低，列出两个互斥假设及各自需要的诊断证据。
4. 如何为现有能力测评设计一道能区分“会运行工具”和“能作系统判断”的题？
5. 比较训练、离线推理、在线推理的首要性能目标与设计取舍。
