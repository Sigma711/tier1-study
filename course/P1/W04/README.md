- **正确性与故障**：能用有限差分梯度检查、anomaly detection 和梯度范数诊断链式法则错误、in-place 版本冲突、梯度爆炸/消失及错误 weight decay。
- **系统设计与评审**：能权衡优化器收敛速度、状态内存、数值稳定性和可恢复性，说明何时 SGD 或 AdamW 更合理。

## 与既有经验的连接

- **数据库内核**：反向图的依赖传播像执行计划的数据流，成立于 DAG 与依赖顺序；失效于梯度是微分量，不是关系元组。
- **存储引擎**：saved tensors 和优化器状态像中间物化与检查点，成立于容量/恢复权衡；失效于其一致性由训练语义而非事务协议定义。
- **计算引擎**：链式法则沿图累积像数据流聚合，成立于拓扑调度；失效于数值微分与普通算子流水线的误差模型不同。
- **分布式系统**：梯度同步前的局部状态可类比副本状态；失效于本课单机优化器不涉及跨副本一致性。
- **可观测性**：loss、梯度范数和 step time 是分层信号；失效于 loss 波动不能单独定位是数据、优化器还是实现错误。
