## 高级工程师面试覆盖

- **原理与推导**：能由 sign/exponent/mantissa 推导 FP32、FP16、BF16、FP8 的范围与精度，使用机器 epsilon 和误差传播界解释舍入与量化误差。
- **源码与产物**：能检查 PyTorch dtype/cast、AMP autocast 与 GradScaler 的算子策略，并识别编译产物中输入、累加和输出精度。
- **性能与实验**：能按元素字节数推导带宽和显存收益，用相同 Shape/Kernel 比较吞吐，并同时报告相对误差、ULP 或任务质量。
- **正确性与故障**：能诊断 overflow、underflow、cancellation、NaN/Inf、loss-scale 溢出和 FP8 scale 选择错误，保留首次异常算子证据。
- **系统设计与评审**：能为权重、Activation、梯度和累加器分别选择精度，在速度、容量、硬件支持与误差预算间取舍。

## 与既有经验的连接

- **数据库内核**：浮点误差像数值 SQL 聚合误差，成立于顺序与类型影响结果；失效于 AI 混合精度还受张量核与训练收敛约束。
- **存储引擎**：低精度格式像压缩编码，成立于空间/带宽换精度；失效于浮点运算误差会逐层传播，不只是解码误差。
- **计算引擎**：混合精度像按算子选物理类型，成立于逐算子代价选择；失效于硬件累加精度和 loss scaling 没有普通类型系统等价物。
- **分布式系统**：低精度状态可减少传输容量；失效于数值近似不是一致性降级，两者风险不可互换。
- **可观测性**：NaN、Inf、scale、误差分布可定位数值失效；失效于只监控最终 loss 会掩盖早期异常来源。
