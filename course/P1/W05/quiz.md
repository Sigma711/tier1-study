# W05 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：浮点数与数值计算、FP32、FP16、BF16、FP8、量化误差。

1. 从指数位和尾数位比较 FP16 与 BF16 的动态范围和有效精度，并各给出更易出现的一种误差。
2. 为什么 FP16 GEMM 常用 FP32 accumulator？用误差累积解释。
3. 把 FP32 tensor 改成 FP16，理论显存和带宽需求如何变化？为什么实际速度未必翻倍？
4. 解释 overflow、underflow、cancellation、NaN/Inf 的区别，并为每种给出可观测证据。
5. 为权重、Activation、梯度和累加器制定混合精度方案时需要哪些正确性门？
