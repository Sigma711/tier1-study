# W09 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：模型训练与生成过程、显存占用模型、推理工作负载。

1. 列出训练显存中的参数、梯度、优化器状态和 Activation，给出随参数量、batch/长度变化的容量式。
2. 解释 prefill 与 decode 的计算形态；为什么用同一个平均 tokens/s 会掩盖差异？
3. 给定输入长度 1000、输出 100，说明生成 loop 中状态如何增长，哪些时间应分别测量。
4. 训练 OOM 与生成 OOM 各列出两个假设，并为每个假设给出内存/时间线证据。
5. 分别为训练、离线生成、交互生成选择吞吐或延迟目标，并说明 batch 策略的取舍。
