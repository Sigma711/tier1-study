## 高级工程师面试覆盖

- **原理与推导**：能分解训练参数/梯度/优化器/Activation 显存，解释 autoregressive prefill 与逐 token decode 的计算差异，并按长度和批量推导工作量。
- **源码与产物**：能定位训练 loop 的 forward/backward/optimizer step 和 generation loop 的 logits、sampling、past key values，核对状态生命周期。
- **性能与实验**：能分别测 step time、tokens/s、峰值显存、prefill latency、decode latency，固定模型、精度、输入/输出长度和 batch。
- **正确性与故障**：能诊断训练 OOM、状态未清零、生成终止条件、采样参数和工作负载混测造成的错误结论，提供内存快照与时间线。
- **系统设计与评审**：能依据训练、离线生成和交互生成的不同目标制定显存预算与批处理策略，但不提前引入后续服务调度机制。

## 与既有经验的连接

- **数据库内核**：训练 step 与生成 loop 像有状态迭代执行，成立于阶段和状态转移；失效于梯度更新与随机采样不是事务执行。
- **存储引擎**：显存预算像 buffer pool 工作集预算，成立于峰值和生命周期；失效于模型状态多为易失张量且无页替换等价语义。
- **计算引擎**：prefill 的大矩阵与 decode 的小步迭代代表两类执行形态；失效于不能用单一算子吞吐代表端到端生成。
- **分布式系统**：不同请求长度可用工作负载分布方法建模；失效于本课不讨论跨设备切分与调度。
- **可观测性**：按训练/prefill/decode 分阶段度量可避免聚合误导；失效于平均 latency 会掩盖长度分布与尾部。
