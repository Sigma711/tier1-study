## 高级工程师面试覆盖

- **原理与推导**：能由 shape/stride 推导地址偏移，给出 \((m\times k)(k\times n)\) GEMM 的 \(2mkn\) FLOPs；掌握分布、\(E[X]\)、\(Var(X)\)、样本均值和估计误差。
- **源码与产物**：能定位 PyTorch `TensorImpl` 的 sizes/strides/storage_offset、广播规则与 `matmul` 分派，并读懂随机张量生成器和 RNG state。
- **性能与实验**：能比较 contiguous/transpose/broadcast 后物化对带宽与 GEMM 吞吐的影响，并用固定种子、样本量和置信区间审查采样结果。
- **正确性与故障**：能诊断 shape 不相容、零 stride 写入别名、非连续 view 误用、矩阵维度错误以及把一次随机样本误当总体规律。
- **系统设计与评审**：能决定何时保留 view、何时物化 contiguous、何时用批量 GEMM，并解释统计估计的成本—精度取舍。

## 与既有经验的连接

- **数据库内核**：shape 推导和广播像类型/列宽推导，成立于执行前约束检查；失效于张量轴没有 SQL 行列、NULL 与集合语义。
- **存储引擎**：stride/view/contiguous 像行列布局与零拷贝切片，成立于地址映射和物化成本；失效于张量 storage 通常无持久化与事务语义。
- **计算引擎**：矩阵乘法和批量维度像向量化算子与分区执行，成立于吞吐模型；失效于 GEMM 的代数规则与关系算子不同。
- **分布式系统**：抽样估计可用于理解随机负载与容量区间；失效于概率收敛不能替代副本一致性保证。
- **可观测性**：均值、方差、分位数与样本量决定指标解释力；失效于统计显著不自动证明系统因果。
