# W63 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：论文复现、对照实验、回归审计、开源贡献准备。

1. 从论文主张提取效应量、方差和样本数，如何判断工程显著性？
2. 如何把论文算法映射到固定 revision 的 file/function 和最小补丁？
3. baseline/ablation 应固定哪些硬件、软件、输入、seed 和统计口径？
4. 哪些 raw result、environment manifest 与 git diff 能发现 cherry-pick 或基线不等价？
5. 复现偏差出现时，如何区分实现错误、环境差异和论文限制并准备贡献？

## 答题与订正

正式学习后记录答案、参考依据和错因。Quiz 用于知识检索，不设计互动式操作题。
