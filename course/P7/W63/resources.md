# W63 · 固定学习资料

以下资料已在课程初始化时固定。授课应优先使用这些一手来源，不得由未来 Agent 随机替换。

**资料状态核验：2026-10-22。**

- [ACM Artifact Review and Badging](https://www.acm.org/publications/policies/artifact-review-and-badging-current) — **选入理由**：ACM 明确区分 Artifact Available、Functional、Reusable 与 Results Reproduced/Replicated，能防止把“代码可下载”“能运行”和“结论被独立复现”混成同一种证据；**支撑 Scope**：论文复现、回归审计；**阅读深度**：逐项区分 available、functional、reusable、results reproduced/replicated。
- [MLPerf Policies](https://docs.mlcommons.org/inference/index_gh/) — **选入理由**：基线、系统描述、accuracy 与审计规则的一手范例；**支撑 Scope**：对照实验、回归审计；**阅读深度**：读 compliance、measurement、submission 与 audit 证据。
- [PyTorch Contributing Guide](https://github.com/pytorch/pytorch/blob/e149fba40596a8181f44e1f318da5fa10d609118/CONTRIBUTING.md) — **选入理由**：PyTorch 的贡献指南把 Issue/PR、测试、Lint、Backward Compatibility 与 Review Gate 写成真实项目准入规则，可据此判断一项研究改动距离可合并贡献还缺什么证据；**支撑 Scope**：开源贡献准备；**阅读深度**：读 issue/PR、测试、lint、backward compatibility 与 review 要求。

如某链接、版本或项目状态发生变化，只能核验并更新引用；不得借机改变本课 Scope。
