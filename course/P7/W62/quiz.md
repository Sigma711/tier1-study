# W62 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：Platform、部署、可观测、压测、资源控制。

1. 由目标并发、服务率、p99 SLO、GPU 容量与冗余推导副本数。
2. Deployment/Service、GPU request、观测 schema 和 load-generator 配置如何构成平台产物？
3. 真实压测必须固定哪些 workload、revision、预热、并发与统计口径？
4. 为什么 Pod Ready 不证明模型语义、资源隔离或 SLO 已达标？
5. 用 rollout、event、trace 和原始压测结果设计上线/回退门禁。
