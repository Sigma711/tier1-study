# W57 · 毕业项目方案：需求、架构、接口、约束、性能目标

## 本课目的

围绕 **毕业项目方案：需求、架构、接口、约束、性能目标** 建立可用于高级 AI Infra 工程判断的知识模型。重点是理解原理、实现位置、性能边界和失效条件，不训练脱离 Agent 的机械操作熟练度。

## 固定 Scope

本课只覆盖以下已经确定的主题：

- 毕业项目方案
- 需求
- 架构
- 接口
- 约束
- 性能目标

这些条目是本课内容边界。授课 Agent 可以补充解释、例子和一手证据，但不得新增课程主题、删除条目或把后续周内容提前替代本课。

## 掌握目标

- 能用自己的语言解释本课全部 Scope，说明各概念之间的因果关系。
- 能指出真实系统中承载这些机制的组件、源码位置或运行证据。
- 能说明关键性能、正确性、可靠性或成本权衡，以及至少一种失效条件。
- 能分别把本课知识连接到数据库内核、存储引擎、计算引擎、分布式系统和可观测性经验，并指出每个类比的失效边界。

## 高级工程师面试覆盖

- **原理与推导**：把需求转换为容量模型：由流量、序列长度、SLO、显存和带宽推导吞吐上界与资源预算。
- **源码与产物**：从接口契约追到候选系统的 scheduler/cache/worker 源码对象，并以架构图明确数据面、控制面和状态边界。
- **性能与实验**：定义 TTFT、TPOT、goodput、峰值显存与 cost/token，规定 workload、硬件、预热、并发和基线。
- **正确性与故障**：列出请求身份、模型版本、缓存归属和容量保护不变量，并用错误预算、故障域和恢复证据评审方案。
- **系统设计与评审**：在范围约束内比较接口稳定性、性能目标、复杂度和可演进性，拒绝无法验证的需求。

## 与既有经验的连接

- **数据库内核**：需求到不变量类似内核语义设计；但模型质量与生成延迟不是传统事务语义。
- **存储引擎**：容量/状态边界可借鉴持久与可重建状态分类；但本周只定义方案，不预设具体缓存实现。
- **计算引擎**：架构图可类比逻辑/物理计划分层；但毕业项目接口必须显式暴露模型和请求约束。
- **分布式系统**：故障域与接口契约类比成立；但方案文档不是一致性证明或实际容错证据。
- **可观测性**：性能目标必须变成可测 SLI；没有 workload/硬件/统计口径的数字不构成目标。
