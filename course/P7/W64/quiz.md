# W64 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：高级技术面试模拟、系统设计、源码分析、项目答辩。

1. 推导训练显存/通信、推理 KV 容量/排队和 Kernel Roofline 时必须声明哪些假设？
2. 如何从仓库入口追到核心数据结构、collective/Kernel，并区分事实与推断？
3. 怎样识别未固定 workload、硬件、预热或统计口径的虚假 speedup？
4. 从哪些不变量与证据分析 OOM、hang、数值漂移、缓存串扰和 SLO 退化？
5. 设计一个同时覆盖容量、接口、故障域、观测、成本与演进的答辩框架。
