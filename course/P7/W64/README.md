# W64 · 高级技术面试模拟、系统设计、源码分析、项目答辩

## 本课目的

围绕 **高级技术面试模拟、系统设计、源码分析、项目答辩** 建立可用于高级 AI Infra 工程判断的知识模型。重点是理解原理、实现位置、性能边界和失效条件，不训练脱离 Agent 的机械操作熟练度。

## 固定 Scope

本课只覆盖以下已经确定的主题：

- 高级技术面试模拟
- 系统设计
- 源码分析
- 项目答辩

这些条目是本课内容边界。授课 Agent 可以补充解释、例子和一手证据，但不得新增课程主题、删除条目或把后续周内容提前替代本课。

## 掌握目标

- 能用自己的语言解释本课全部 Scope，说明各概念之间的因果关系。
- 能指出真实系统中承载这些机制的组件、源码位置或运行证据。
- 能说明关键性能、正确性、可靠性或成本权衡，以及至少一种失效条件。
- 能分别把本课知识连接到数据库内核、存储引擎、计算引擎、分布式系统和可观测性经验，并指出每个类比的失效边界。

## 高级工程师面试覆盖

- **原理与推导**：在白板条件下推导训练显存/通信、推理 KV 容量/排队和 Kernel Roofline，并明确假设与数量级。
- **源码与产物**：对给定真实仓库从入口、核心数据结构到 Kernel/collective 追踪调用链，区分源码事实、推断和未知。
- **性能与实验**：审查 benchmark 是否固定 workload、版本、硬件、预热与统计口径，并能识别错误 speedup。
- **正确性与故障**：从不变量出发分析 OOM、hang、数值漂移、缓存串扰和 SLO 退化，提出能证伪根因的证据。
- **系统设计与评审**：完成包含容量、接口、故障域、观测、成本与演进的 AI Infra 设计，并能防守项目取舍。

## 与既有经验的连接

- **数据库内核**：用事务/执行器经验提出不变量和源码追问；但不能把 ACID 套到所有训练/推理状态。
- **存储引擎**：用布局、缓存、恢复经验评审数据路径；但必须先区分权重、optimizer、KV 的不同生命周期。
- **计算引擎**：用优化器、算子和调度经验解释执行；但需补足 GPU SIMT、张量 shape 与模型语义。
- **分布式系统**：用故障域、背压和一致性评审架构；但 collective 和共识的保证不可混同。
- **可观测性**：要求每个结论可回到指标、trace、profile 或源码；相关性只能生成假设，不能直接宣判因果。
