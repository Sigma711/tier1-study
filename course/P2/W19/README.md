# W19 · GPU Kernel 专题综合学习与考核

## 本课目的

围绕 **GPU Kernel 专题综合学习与考核** 建立可用于高级 AI Infra 工程判断的知识模型。重点是理解原理、实现位置、性能边界和失效条件，不训练脱离 Agent 的机械操作熟练度。

## 掌握目标

- 能用自己的语言解释本课全部 Scope，说明各概念之间的因果关系。
- 能指出真实系统中承载这些机制的组件、源码位置或运行证据。
- 能说明关键性能、正确性、可靠性或成本权衡，以及至少一种失效条件。
- 能分别把本课知识连接到数据库内核、存储引擎、计算引擎、分布式系统和可观测性经验，并指出每个类比的失效边界。

## 高级工程师面试覆盖

- **原理与推导**：能为给定 GPU Kernel 同时提交 FLOPs、字节数、arithmetic intensity、occupancy 资源界与 work/span，解释哪个上界主导。
- **源码与产物**：能从 Triton/CUDA/CUTLASS 源码追到 IR、PTX/SASS、launch 配置和 profiler 记录，建立可审查的逐层对应。
- **性能与实验**：能构造跨 Shape、dtype、布局的正确性矩阵和基准，以库实现为基线报告分位延迟、吞吐、资源与误差。
- **正确性与故障**：能用参考实现、边界 Shape、sanitizer、racecheck 和首次失败证据区分算法错、数值错、并发错与测量错。
- **系统设计与评审**：能评审自定义 Kernel 是否值得长期维护，覆盖硬件兼容、回退路径、调优范围、证据可复现性和性能收益。

## 与既有经验的连接

- **数据库内核**：Kernel 评审像核心算子评审，成立于正确性、代价和回归门；失效于 GPU 数值与硬件特异性更强。
- **存储引擎**：布局、局部性和容量预算方法可复用；失效于考核对象是易失设备内存，不含持久化协议。
- **计算引擎**：从算法到 Kernel/IR 的链路像物理算子实现；失效于不能用单个 Shape 的微基准代表端到端计划。
- **分布式系统**：回退、兼容矩阵与故障域思维可用于发布评审；失效于本课综合考核仍限定单 GPU Kernel。
- **可观测性**：原始输出、timeline、counter、PTX/SASS 构成完整证据链；失效于任何单层证据都不能独立证明根因。
