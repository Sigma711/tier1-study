# W56 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：SLO、容量规划、成本模型、弹性伸缩、故障注入与恢复。

1. 由到达率、服务时间、并发和目标 p99 推导容量余量，并解释重尾请求的影响。
2. 如何定义 TTFT/TPOT、goodput、错误预算和 cost/token 的统一 SLI 口径？
3. 扩缩容阈值过近为何会振荡，模型加载冷启动如何改变控制环？
4. 故障注入后应使用哪些队列、扩容、恢复和错误预算证据判定恢复成功？
5. 在冗余、成本、冷启动、RTO 与 SLO 间设计可量化容量方案。
