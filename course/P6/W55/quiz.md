# W55 · 简短 Quiz

本课 Quiz 固定检验以下知识范围：DCGM、NVML、CUPTI、Nsight、OpenTelemetry、端到端 Tracing。

1. 比较 NVML、CUPTI、Nsight、DCGM 与 OpenTelemetry 的数据对象、粒度和使用场景。
2. 由采样周期、事件率和 payload 推导观测数据量与潜在扰动。
3. 为什么 NVML polling、CUPTI Activity、Nsight report 不能当作同层替代品？
4. 如何用 dropped records、时间戳、device/process/request identity 诊断 trace 断链？
5. 设计常驻监控到低层 Profile 的证据链，并说明开销控制。
