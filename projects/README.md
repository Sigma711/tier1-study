# 五项渐进式工程研究

这五项成果随 64 周主课程推进，用于把知识落实到真实源码、测试和性能证据，不是额外课程，也不要求学习者手工完成全部操作。

1. [GPU Kernel 系统研究](01-gpu-kernel-study/README.md)
2. [Mini AI Compiler](02-mini-ai-compiler/README.md)
3. [Mini LLM Inference Engine](03-mini-llm-inference-engine/README.md)
4. [Distributed AI Runtime](04-distributed-ai-runtime/README.md)
5. [Production AI Platform](05-production-ai-platform/README.md)

Coding Agent 负责实现、测试、测量和证据整理；学习者负责技术目标、正确性判断、性能解释、架构权衡和答辩。质量以可复验的技术结果衡量，不以代码行数或操作次数衡量。
